# Переход на пакетную установку OpenProject

Целевая среда: Windows PowerShell 5.1, WSL Debian, OpenProject 17.9.2.

Контроллер использует `op-tray-package.sh`: он проверяет пакетный CLI, systemd
и экземпляры web/worker, затем управляет только службами `openproject*.service`.
Миграции и чтение их статуса используют окружение `/usr/bin/openproject run`,
без установки зависимостей и выбора пользовательских Ruby/Node.js.

Мониторинг выполняется в отдельном runspace. Интерфейс и IPC используют кеш;
результат проверки, начатой до операции или изменения настроек, отбрасывается.
Первое нажатие до получения состояния ожидает проверку. Явная команда меню
отменяет ожидающее нажатие. Ошибка миграции не запускает службы автоматически.

Старый стандартный URL переносится только после подтверждения пакета,
с резервной копией настроек. HTTPS сохраняет имя хоста для проверки сертификата.
Для HTTP localhost используется IPv4: в проверенной Windows-среде запрос к
localhost зависает, а запрос к 127.0.0.1 возвращает 200 через WSL.
Для холодного запуска состояние WSL фиксируется до пробуждения дистрибутива.

## Проверки 19 октября 2026

- Существующие наборы: desktop (52 проверки), интеграция трея, диалог плагина,
  установщик, inspector и протокол плагина. Windows IPC требует запуска вне
  ограниченной песочницы; внутри неё Named Pipe/WebSocket дают таймауты.
- Новые наборы: `tests/Test-PackageCore.ps1` и `tests/Test-PackageScripts.sh`.
  Проверяют состояния служб/HTTP, ошибки CLI/WSL, порядок миграций, сохранение
  настроек, HTTPS, выбор холодного таймаута и точные цели systemctl.
- Живая установка: диагностика, подсчёт миграций, остановка, запуск, перезапуск,
  миграции с перезапуском, журналы служб и миграций. После цикла нет ожидающих
  миграций; PostgreSQL и прокси остаются доступны после остановки OpenProject.
- Установленное приложение обновлено с сохранением настроек и журналов.
  Старый адрес перенесён с резервной копией, остальные предпочтения сохранены.
  Обычный ярлык меню «Пуск» выполнил миграции и перезапуск; итоговый IPC-статус:
  `Running`, `busy=false`, пустая ошибка. Его вызов открытия браузера выполнен.
- Фактически установленный плагин отдельно прошёл тот же протокольный набор
  в изолированном эмуляторе. Его `connection.json` указывает на обновлённый EXE.
- До миграций создана и проверена копия PostgreSQL:
  `/home/openproject/backups/openproject-tray/before-tray-migration-20261019-202115.dump`.
- Нажатие физической кнопки StreamDock требует проверки на устройстве;
  автоматические тесты используют эмулятор хоста и приватный контроллер.

Установщик сохранит существующие настройки и журналы. После первого запуска
контроллер переносит старый стандартный адрес с резервной копией. Обновление
не меняет профили StreamDock; протокол IPC остаётся прежним. Для проверки уже
установленного плагина передайте путь к его папке вторым аргументом Node:
`node tests/Test-PluginProtocol.js <папка-com.openproject.tray.sdPlugin>`.

Требования и решения основаны на согласованном в чате плане. Работа выполняется
в ветке `codex/packaged-openproject`; изменения пользовательской базы ограничены
штатной командой миграций. Два замечания независимого ревью (отложенное нажатие
и HTTPS localhost) воспроизведены тестами перед исправлением.

По запросу пользователя стандартный адрес изменён на `http://127.0.0.1`.
Предыдущий пакетный стандарт `http://localhost` также переносится с резервной копией.
